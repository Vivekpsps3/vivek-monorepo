Encryption demo

ECDH and AES-GCM protect a prompt in the browser before it is sent to the server.

How the demo works

  1. ECDH establishes a shared key; the browser encrypts your prompt with AES-GCM.
  2. The server decrypts the prompt and sends it to a local LLM.
  3. The LLM reply returns to the browser as ordinary text; this demo does not wrap the reply in AES-GCM.

The server can read your prompt after decrypting it. Do not enter private or sensitive information.
