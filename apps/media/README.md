# Media

Private journal for movies, series, books, songs, albums, and games. It lives at `/media/` on the suite and uses the finance sign-in. Personal ratings and notes stay in `media.db`.

Search can enrich a title from TMDB, MusicBrainz, the Cover Art Archive, Open Library, or RAWG. Those calls are public metadata only. The journal still works when the providers are down or unconfigured: add the title by hand.

See [docs/MEDIA.md](../../docs/MEDIA.md).
