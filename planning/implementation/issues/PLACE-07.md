## Steps

1. Establish current source behavior and live prerequisites/claims; baseline actual facts before changing consumers.
2. Compose selected-day facts, channel contributions, learning annotations, honest coverage and exact Visit actions without inventing a life-quality score.
3. Use UX-05 date orientation and discoverable legend in both modes; add selection patterns/outlines, clear range/coverage and scoring explanation.
4. Preserve birthday/age preferences, partial spans, future/planned trips and Life table; show named loaded moments lazily with truncation labels.
5. Review ordinary/empty/partial/rich Year and Life compositions; delete duplicated selection/orientation explanations only when actual replacements exist.
6. Run launch-expanded profiles plus actual-diff root gates locally; record exact acceptance, visual, removal and verification evidence before opening the PR.
