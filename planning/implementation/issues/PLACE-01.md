## Steps

1. Establish current source behavior and live prerequisites/claims; baseline actual facts before changing consumers.
2. Capture the current synthetic rendered baseline and actual route payload/request/frame measurements; identify source-only assumptions explicitly.
3. Produce editable local vector asset studies and static rendered compositions for the scene/atlas states and viewports specified in experience.md; record provenance and asset grid/baseline rules.
4. Storyboard first habit, check/Undo, object inspection, date passage and placement with exact labels, state transitions and keyboard equivalents.
5. Review composition/legibility/identity and establish the reference performance profile; resolve documented design defects before expanding the catalog.
6. Run launch-expanded profiles plus actual-diff root gates locally; record exact acceptance, visual, removal and verification evidence before opening the PR.
