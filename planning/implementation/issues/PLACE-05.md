## Steps

1. Establish current source behavior and live prerequisites/claims; baseline actual facts before changing consumers.
2. Bind a short lot-specific static/animated response to the existing authoritative check-in result, not input intent; separate pending state from earned effect.
3. Keep duplicate suppression scoped to the habit; support independent rapid actions and correct backdated labels.
4. Implement failure/retry/Undo/reduced-motion feedback and disposal so old work cannot celebrate on another route/day/owner.
5. Capture the first playable garden → check → inspect → dated visit sequence with exact labels and keyboard equivalent.
6. Run launch-expanded profiles plus actual-diff root gates locally; record exact acceptance, visual, removal and verification evidence before opening the PR.
