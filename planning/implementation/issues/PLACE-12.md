## Steps

1. Establish current source behavior and live prerequisites/claims; baseline actual facts before changing consumers.
2. Use the existing small cast with coherent art/personality and a finite local fact-conditioned vignette catalog; each helps orient, notice or explain.
3. Make resident inspection explicit with dismissible text and a static/reduced-motion equivalent; keep targets stable and tasks unobstructed.
4. Add restrained offscreen/hidden-paused ambient details; optional original sound is default off and requires explicit choice/gesture with mute.
5. Handle no new records/long absence/max level warmly without invented recaps, pressure, obligations or private fact-conditioned dialogue.
6. Run launch-expanded profiles plus actual-diff root gates locally; record exact acceptance, visual, removal and verification evidence before opening the PR.
