# Town design

The owner settled direct object/building selection, a 3D yet 2D feel, all discussed
game systems and the compact practical Hub on 2026-11-17. The selected direction
is now the [full design](design.md), with the [common acceptance contract](acceptance.md)
and [published small issues](issues.md). This replaces the earlier alternatives.

The design includes ten connected buildings across six districts, four Home rooms,
useful private Finance/Health interiors, culture collections, a travel terminal,
Library study, photo galleries, optional quests, six residents, twelve discoveries,
two minigames and a precisely bounded cosmetic economy. Six existing habit lots
and all canonical source/progression semantics survive their presentation change.

Use the [execution queue](../implementation/README.md) for priority and readiness;
the issue map is a scope index. Saved World concepts move before its standalone
presentation is removed. No existing data is disposable merely because a new room
replaces its old screen.
