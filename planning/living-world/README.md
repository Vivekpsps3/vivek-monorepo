# Living World — retained design and evidence

The 2026-11-17 owner-selected [suite and Town design](../product-revamp/README.md)
replaces this project's former three-experience composition. Town uses direct
selection and layered isometric rooms; Pixels holds dated memory exploration;
standalone World presentation retires only after concepts, history and links migrate.
The compact practical Hub remains home. All discussed game systems and full workout
sessions plus PRs are selected in the new design.

The [single execution queue](../implementation/README.md) owns future work. Former
PLACE-02–14 packets are retained requirement trackers under `implementation/scopes/`,
not executable leaves. The [small issue map](../product-revamp/issues.md) and exact
new packets replace their delivery slices; the requirement ledger assigns every
original acceptance row to one accountable child.
